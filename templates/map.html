Graph implementation

  • The canteen is a graph: each place is a node and each walkway is an edge. It is stored as an adjacency list: every place keeps the list of places next to it. The matrix further down shows the same graph as an adjacency matrix.
  • BFS uses our own Queue. It visits everything 1 step away, then 2 steps away, and so on, so the first time it reaches your goal is the shortest route.
  • DFS uses our own Stack. It dives down one path as far as it can, then backs up. It finds a route, not always the shortest.
  • Press Play: orange places are visited, dashed blue places are waiting in the queue or stack, and the green route is the final path with a walker following it.
