Phase 4: problem-solving algorithms

  • Greedy (change maker): always take the biggest note or coin that still fits. For Indian currency this gives the fewest pieces. Used for cash orders in your cart.
  • Dynamic programming (budget meal planner): 0/1 knapsack. A table stores the best value for every smaller budget, so no combination is tried twice. Value of a dish grows with how many were sold.
  • Backtracking (group seating): try a table for a group, go on to the next group, and undo the choice when stuck or when it wastes more seats than the best plan so far.
