Tree implementation

  • Every dish sits in a TreeNode with a left and a right pointer. A tree where each node has at most two children is a binary tree.
  • It is a binary search tree: names earlier in the alphabet go left, later ones go right.
  • Insert: start at the root, go left or right until there is an empty spot, and put the new node there. Search: the same walk, so every step skips about half of the remaining dishes.
  • Balanced inserts the middle dish first, so the tree stays short (about log2 n levels). Insertion order inserts in menu order, so it can lean to one side and searches take longer. Compare the heights above the tree.
  • Inorder (Left, Root, Right) gives the menu A to Z. Preorder (Root, Left, Right) lists a parent before its children. Postorder (Left, Right, Root) lists children before their parent.
  • Press a traversal button to watch it walk the tree, or search a name to see the path light up.
