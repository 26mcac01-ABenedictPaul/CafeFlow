Searching and sorting

  • Linear search checks dishes one by one from the start: up to n comparisons.
  • Binary search needs a sorted array. It checks the middle, then discards half each step: about log2(n) comparisons. We copy the linked list into an array first, because a linked list cannot jump to the middle.
  • Insertion sort slides each dish back into place: O(n^2) in general, but quick on small or nearly sorted lists, so we use it for the live list of pending orders.
  • Merge sort splits the list in halves, sorts each and merges them: always O(n log n). We use it for the menu and the order report.
  • Press Start race: both sorts run on the same list at the same speed, and both searches look for the same dish. The counters are the real comparison counts from our code.
